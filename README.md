# SEO backup

Копии таблиц и правил проекта «Усиление работы с SEO».

| Папка | Что там | Кто обновляет |
|---|---|---|
| `sheets/<Таблица>.xlsx` | полная копия таблицы с форматированием | скрипт в Google, каждый вечер |
| `sheets/<Таблица>/<Лист>.csv` | данные каждого листа — в истории видно, какие ячейки менялись | скрипт в Google, каждый вечер |
| `rules/` | правила по карточкам, таблицам и зоне ответственности SEO | Claude, каждый вечер |
| `scripts/` | скрипты бэкапа | — |

Таблицы: Выгрузка Miraterri, Выгрузка ECOSTYLE, Выгрузка Caprifash, Моноподы, Выгрузка Спорт.

Диалоги с Claude сюда автоматически не попадают — их выгружают вручную через экспорт данных аккаунта Claude и при желании кладут в папку `dialogs/`.

## Как включить ежедневный бэкап таблиц (один раз, ~5 минут)

**1. Токен GitHub.** github.com → аватар → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token.
- Repository access: **Only select repositories** → `seo-backup`
- Permissions → Repository permissions → **Contents: Read and write**
- Expiration — на ваше усмотрение (после истечения бэкап остановится, придёт письмо об ошибке).
Скопируйте токен (`github_pat_…`). Никому его не пересылайте, в том числе в чат.

**2. Скрипт.** Откройте https://script.google.com → **Новый проект** → назовите «SEO backup».
Удалите всё в файле `Код.gs` и вставьте содержимое `scripts/apps-script-backup.gs` из этого репозитория. Сохраните (Ctrl+S).

**3. Токен в скрипт.** Слева ⚙️ **Настройки проекта** → внизу **Свойства скрипта** → Добавить свойство:
`GITHUB_TOKEN` = ваш токен. Сохранить.

**4. Проверка.** Вернитесь в редактор, вверху выберите функцию `dailyBackup` → **Выполнить**. Google попросит разрешения (доступ к таблицам, внешним запросам и почте) — разрешите. Через несколько минут в репозитории появятся коммиты «Бэкап «…» дата».

**5. Расписание.** Выберите функцию `installDailyTrigger` → **Выполнить**. Готово: бэкап будет запускаться каждый вечер около 21:30. Если что-то сломается — придёт письмо на почту.
