# Miraterri — вакуумные пакеты (таблица «Выгрузка Miraterri»)

- Цель — довести SEO-работу до 10/10; результаты в «Выгрузка Miraterri».
- Для наборов пакетов разных размеров «Длина, см» / «Ширина, см» не заполняются (можно указать размер только одного пакета — это вводит в заблуждение и путает переключатель склейки); размеры только у наборов одного размера.
- #Хештеги не заполняются ни в одной карточке — уводят аудиторию.
- «Вес товара, г» в карточках не заполняется (убран сознательно); габариты пакета — только у наборов одного размера, где размер есть в артикуле.
- Изменения карточек записываются с датой в недельной ячейке артикула на листе «Работа» (например «08.10. изменена комплектация»).
- Стандарт аннотации: длина не важна, важно прямое вхождение топ-3 ВЧ и топ-3 СЧ ключей, плюс размерные запросы, если хорошо продают.
- С 27.10.2026 для всех SEO-проектов: «Соответствие запросу» (СЗ) по каждому из этих ключей ≥ 90, проверка еженедельно в листах «Свод арт.».
- Еженедельный SEO-анализ — по вторникам (в день еженедельной выгрузки «Где товар»).
- ИЦ берётся из таблицы «ВБ ИЦ»: сводка по кабинетам + лист «Miraterri».
- «ЧВНМВП» = инструмент Ozon «Что влияет на место в поиске»; из него выгружаются листы «Где товар <дата>».
